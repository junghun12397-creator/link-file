# 프렙 카페 운영 관리

EPIC 1·2(S01~S10)는 사용자 확인 완료. EPIC 3(S11~S15)의 입고·폐기·마감 실측 기록과 전체 JSON 백업·복원을 구현했다. EPIC 3은 사용자 확인 전 완료로 판정하지 않는다. Vercel 배포는 아직 수행하지 않았다. 현재 검사 상태는 docs/05_테스트결과.md에 기록한다.

## 로컬 실행

Node 22.12 이상, npm 사용. 현재 확인 환경의 실제 버전은 docs/05_테스트결과.md에 기록한다.

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173/#/sales 에서 확인한다. 포트는 고정이며 다른 포트·브라우저·프로필은 별도 저장소다. 서버 종료 후 위 명령으로 다시 실행할 수 있다.

## 검사

```sh
npm run typecheck
npm run test -- --run
npm run test:e2e
npm run build
```

화면 검사는 Windows Edge를 기본 사용한다. 다른 환경은 CAFE_BROWSER_PATH에 설치된 Chromium 계열 브라우저의 실행 경로를 지정한다. 자동 검사는 새 브라우저 프로필에서 실행하며 사용자의 저장소를 지우지 않는다.

가상 원본 JSON은 읽기 전용 초기 자료로 사용하고, 실제 변경은 브라우저 IndexedDB에만 저장한다. 원본 엑셀·JSON을 수정하지 않는다. 새로고침 후에도 저장 자료를 유지한다. 개발 서버는 이 PC에서만 접속하도록 127.0.0.1에 연결한다.

`재고 기록 & 잔량`에서 입고·폐기·실제 재고를 기록하고, `비용 & 데이터 보관`에서 전체 JSON 파일 백업·복원을 사용한다. 복원은 현재 전체 자료를 교체하므로 먼저 백업하고 확인 내용을 읽는다. 1차에는 재고 기록 수정·삭제를 제공하지 않는다.

가상 자료로 먼저 확인한다. 브라우저 데이터 삭제·비공개 창·다른 주소·기기 고장으로 자료를 잃을 수 있으므로 백업 파일을 별도 보관한다. 파일은 암호화되지 않으므로 접근 권한을 관리한다. GitHub·Vercel에 운영 기록이 자동 보관되는 구조가 아니다.

GitHub 업로드 대상은 코드·요구사항·시안·검사 코드와 명시된 가상 원본 자료다. 운영자료·다운로드 백업·비밀 설정·검사 산출물·node_modules·dist는 제외한다. 엑셀 가져오기·기간 확대·예측·발주 추천은 2차이며 아직 구현하지 않았다.
