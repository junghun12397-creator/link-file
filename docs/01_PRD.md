# 프렙 카페 운영 관리 제품 요구사항 문서(PRD)

작성일: 2026-10-12  
상태: 자료 검토 완료, 추천한 1차·2차 범위 사용자 승인 완료. 세부 기준은 후속 설계에서 결정

PRD는 프로그램의 목적, 필요한 기능, 완료 기준을 정리한 문서다. MVP는 가장 중요한 사용 흐름을 먼저 완성하는 최소 기능 제품이다.

## 1. 자료에서 확인한 사실

검토 자료: `프렙 카페/매장운영데이터.xlsx`, `프렙 카페/매장운영데이터.json`, `프렙 카페/데이터설명.md`.

프렙 카페의 가상 운영 자료다. 기록 기간은 2025-07-01~2026-09-18 마감까지이며 영업달력만 2026-09-30까지 있다. 금액은 원화·부가세 제외, 재료 단위는 g·ml·개다. 엑셀과 JSON은 같은 기록의 두 형식이므로 한 형식으로 한 번만 반영한다.

| 기록 | 수 | 확인한 내용 |
| --- | ---: | --- |
| 공급사 | 3 | 공급사 번호·이름 |
| 재료 | 11 | 단위, 구매용량·가격, 공급사, 납기·안전재고 영업일 |
| 메뉴 | 8 | 이름, 판매기준가, 음료·디저트 구분, 레시피 버전 |
| 레시피 | 22 | 메뉴 1개당 재료 사용량, 포장 판매에만 적용되는 재료 |
| 재료가격이력 | 33 | 적용시작일별 구매가격·용량 |
| 영업달력 | 457 | 영업·마감 여부, 날씨, 메모 |
| 판매기록 | 6,112 | 날짜·메뉴·매장/포장별 수량, 당시 단가, 할인, 순매출, 결제수수료, 개당 식재료·포장 원가 |
| 초기재고 | 11 | 첫날 영업 시작 전 재료별 수량 |
| 재고기록 | 1,515 | 입고, 폐기, 실사조정과 실측수량 |
| 월비용계획 | 120 | 월별 8가지 비용항목의 금액 |
| 비용기록 | 3,560 | 월비용을 날짜별로 나눈 금액과 배분기준 |
| 자료정보 | 10 | 출처, 매장명, 기록 기간 등 |

엑셀에서 위 기록 수와 항목을 확인했으며 JSON의 대응 기록 수와 일치한다. 엑셀에는 설명용 `데이터안내` 시트도 있다. 판매는 주문 한 건씩이 아니라 날짜·메뉴·채널별 합계다. 예를 들어 “하루 동안 매장에서 판매한 아메리카노 20잔”이 한 기록이다.

비용항목은 임차료, 인건비, 사업주 부담 보험료, 관리비, 수도광열비, 통신·소프트웨어, 광고비, 소모품·청소비다. JSON의 `settings`는 비어 있다. 앞으로의 운영 정책이 합의됐다는 근거는 없다.

제한적으로 확인한 결과 판매번호와 날짜·메뉴·채널 조합의 중복은 없었고, 판매와 레시피가 참조하는 메뉴 및 레시피가 참조하는 재료는 존재했다. 모든 금액과 재고의 정확성을 검증한 것은 아니다.

## 2. 기획할 때 주의할 점

- **비용 중복:** 월비용계획과 일별 비용기록은 같은 비용이다. 서로 다른 지출로 더하면 비용이 부풀려진다. 재료 입고 비용과 판매에 사용된 원가의 관계도 정해야 한다.
- **미마감과 일부 기간:** 2026-09-19~09-30의 12일은 미마감이다. 판매 0원인 확정 실적으로 보지 않는다. 연간 결과도 일부 기간만 포함한다.
- **과거 기록과 새 기준:** 당시 단가·원가·수수료와 기존 비용 배분은 과거 기록이다. 새 판매나 과거 기록 수정에 사용할 기준은 별도 합의가 필요하다.
- **단위와 포장:** 구매가격은 구매용량 전체의 가격이다. 개당 원가는 메뉴 1개 기준이며 포장컵 등은 포장 채널에만 적용된다.
- **실사:** 실제로 세어 본 재고를 실측수량이라 한다. 입고는 양수, 폐기는 음수, 실사조정은 양수·음수 모두 있다. 조정량과 실측수량을 별도 입고처럼 함께 반영하지 않도록 정책을 정해야 한다.
- **예측과 발주:** 납기·안전재고 일수는 영업일 기준이다. 관련 자료가 있어도 예상 판매량이나 발주 추천 방법이 정해진 것은 아니다.
- **빈칸:** 해당 없음 또는 미입력이므로 실제 0과 구분한다.

## 3. 제품 목적과 핵심 흐름

카페 운영자가 판매·비용·재고를 관리하고, 어떤 메뉴가 수익에 도움이 되는지와 매장 손익·재료 잔량을 연결해서 확인하도록 돕는다.

**판매 기록 입력 → 메뉴 수익성 확인 → 같은 기간의 손익과 해당 시점의 재료 잔량 확인**

판매·손익은 선택 기간의 실적이고 재고는 특정 시점에 남은 양이다. 사용자가 두 기준을 알아볼 수 있어야 한다.

주 사용자는 카페 운영자다. 1차는 한 매장·한 운영자가 사용하는 초기 제품으로 진행한다.

## 4. 확정한 범위의 전제

전체 요청은 판매·비용 편집, 엑셀 양식·가져오기, 재고 기록, 수익성·기간 실적·예상 손익·부족 재료·발주량, 일·주·월·분기·반기·연간 조회, 저장·백업·복원이다.

사용자가 2026-10-12에 “선택을 모두 추천으로” 요청하여 기존 추천안 A와 문서의 추천 범위를 승인했다. 아래 단계 구분은 승인된 제품 범위다. 2차 항목도 제품 요구로 유지한다.

1차는 제공된 메뉴·재료·레시피·가격이력·기존 기록을 활용하고 기초 정보의 자유로운 편집은 2차에 포함한다. 원본 자료를 초기 제품에 반영하는 작업과 사용자가 엑셀을 반복해서 가져오는 기능은 구분한다.

계산식, 화면 디자인, 기술, 상세 동작, 코드는 이번 문서에서 정하지 않는다. 아직 추천안을 제시하지 않은 수익성·손익·재고의 세부 기준은 미정으로 유지하며 후속 문서에서 정리한다. 사용자 요청에 따라 이미 제시한 추천 선택은 다시 질문하지 않는다.

## 7. 1차 완료 확인 기준

구체적인 기대 금액·수량과 계산식은 후속 단계에서 정한다.

1. 제공 자료로 기존 판매·비용·재고를 확인하고 엑셀·JSON의 동일 기록이 두 번 반영되지 않는다.
2. 판매 입력 후 해당 메뉴의 실적·수익성, 선택 기간의 손익, 관련 재료 잔량까지 확인한다.
3. 판매·비용 수정·삭제가 합의한 기준에 따라 관련 결과에 일관되게 반영된다.
4. 입고·폐기·실제 재고 기록과 잔량이 합의한 재고 정책에 맞는다.
5. 과거 판매 기록, 수정된 기록, 새 기록의 취급이 합의한 기준과 일치한다.
6. 포장 재료의 적용 범위와 g·ml·개 단위를 구분하며 월계획·일별 비용을 이중 반영하지 않는다.
7. 미마감 날짜·실제 판매 0·빈칸을 구분하고 일부 기간을 전체 연간 실적으로 오해하지 않게 한다.
8. 저장 후 다시 열어 기록을 확인하고 전체 백업·복원 후에도 기록의 연결을 유지한다.
9. 배포된 프로그램에서 판매 입력부터 수익성·손익·재료 잔량 확인까지 이어진다.

## 8. 4시간 작업 계획

| 단계 | 시간 | 목표 |
| --- | ---: | --- |
| 기획 | 30분 | 자료 검토, 필수 정책·1차 범위 합의 |
| 화면 설계 | 20분 | 핵심 흐름에 필요한 정보와 이동 흐름 정리 |
| 개발 | 115분 | 승인된 최소 기능 연결 |
| 검사 | 45분 | 기록 변경, 포장 재료, 비용 중복, 미마감, 실사, 백업·복원 확인 |

목표 시간이며 완료 보장은 아니다. 자료 검토 시간도 기획에 포함한다. 제공 자료 활용, 초기 사용 대상 제한, 기본 기록 관리가 전제다. 정책 협의가 길어지거나 추가 요구가 생기면 검사·배포 시간을 확보하도록 범위를 재협의한다. 범위 변경은 사용자 결정 사항이며 자동으로 기능을 제외하지 않는다.

## 9. 승인한 선택과 남은 설계 항목

사용자의 추천안 일괄 선택에 따라 다음을 확정했다.

- A안인 핵심 흐름 우선으로 진행한다.
- 한 매장·한 운영자가 제공된 기초 정보를 활용한다.
- 판매는 날짜·메뉴·매장/포장별 합계로 관리한다.
- 1차는 판매·비용 직접 편집, 메뉴 수익성, 일·월 실적·손익, 기본 재고 기록·잔량, 저장·전체 백업·복원이다.
- 엑셀 양식·가져오기, 나머지 기간 조회, 예상 손익, 부족 판단·발주 추천, 기초 정보 편집과 추가 분석은 2차다.

추천한 이유는 “오늘 라테 20잔을 입력한 뒤 남는 금액과 우유 잔량 확인”까지 핵심 흐름을 검증하면서 4시간 범위에 집중할 수 있기 때문이다.

다음 항목은 아직 구체 추천안을 제시하지 않았으므로 승인된 범위와 구분한다. 자료의 과거 기록을 앞으로의 제품 정책으로 임의 확정하지 않는다. 이번 PRD에서 정하지 않기로 한 세부 내용은 후속 설계에서 다룬다.

| 순서 | 정할 내용 | 필요한 이유 |
| --- | --- | --- |
| 1 | 메뉴 수익성·손익·재고의 후속 기준 | 승인된 기능을 일관되게 연결하기 위한 의미와 정책 정리 |
| 2 | 메뉴 수익성에 포함할 비용과 평가 여부 | 식재료·포장·수수료까지 볼지, 임대료 등까지 나눌지에 따라 의미가 달라짐 |

## 10. 자료 검토의 기획 반영

스프레드시트 검토 지침에 따라 원본을 변경하지 않고 엑셀 항목·기록 수를 확인했다. 준비된 메뉴·레시피·가격·초기재고를 1차에서 활용하는 범위를 제안하고, 설명서의 비용 중복·미마감·실사·과거 원가 주의사항을 제품 요구와 완료 기준에 반영했다.
